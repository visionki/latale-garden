# LaTale Garden

彩虹岛台服非官方 Windows 启动器，让乱码兼容启动、等待游戏和恢复原区域设置在一个图形界面中完成。

**下载一个 `LaTaleGarden.exe` 即可使用。** 可以放在桌面、下载目录或游戏目录；界面、美术素材和运行配置均内置，旁边不需要 `.config`、DLL 或素材文件。设置与运行记录统一保存在当前 Windows 用户的 `%LOCALAPPDATA%\LaTaleGarden`。

[下载 EXE](https://github.com/visionki/latale-garden/releases/download/v1.0.0/LaTaleGarden.exe) · [发布说明](https://github.com/visionki/latale-garden/releases) · [反馈问题](https://github.com/visionki/latale-garden/issues)

## 为什么做这个启动器

彩虹岛台服在部分简体中文 Windows 环境下会出现乱码。已有辅助工具采用“启动前临时切换到繁体系统区域，检测到游戏后再切回”的方式，但等待时间不足、误认已有游戏进程、异常退出后恢复不完整等情况，会让使用过程不稳定，也难以判断失败原因。

LaTale Garden 保留这条兼容启动路线，把操作整理为“选择游戏目录 → 启动 → 在官方启动器开始游戏”，并记录启动前的真实区域设置，增加等待、取消和恢复处理。主要目标是**让台服兼容启动更容易操作、更容易排查问题，并尽量减少系统区域未恢复的情况**。

这是首个公开测试版。目标平台为 Windows 10 / 11 x64；**Win10 的免重启乱码修复、实际切换区域后的游戏内文字，尚未完成实机验收。** 已完成的检查见 [验证记录](VALIDATION.md)。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 原生图形界面 | WPF 窗口，提供目录选择、兼容模式、启动状态、设置和日志页。 |
| 单 EXE 分发 | 美术、界面与运行选项内置，无安装程序，无旁边的配置文件或素材目录。 |
| 记住游戏目录 | 首次选择 `LaTaleLauncher.exe`；以后自动读取。放在游戏目录首次运行时可识别同目录游戏。 |
| 繁体兼容启动 | 保存原区域与代码页，临时设置 `zh-TW`，再调用官方启动器；需要 Windows 管理员授权。 |
| 标准启动 | 关闭繁体兼容模式后，仅启动并监控游戏，不修改系统区域。 |
| 等待与状态识别 | 匹配实际游戏路径、新进程及创建时间；等待窗口稳定和初始化缓冲，减少过早恢复。 |
| 异常恢复 | 取消、超时、启动失败和界面退出会进入恢复；辅助进程异常退出时由独立恢复进程接管。 |
| 保留恢复记录 | 修改前持久保存原值；恢复失败保留记录，下次打开提供恢复入口。 |
| 本地日志 | 查看与导出检查、启动、恢复记录，便于定位问题；不会自动上传。 |
| 窗口与托盘操作 | 切回正在运行的游戏；可选启动成功后收起到托盘。 |

官方启动器仍负责更新、登录和开始游戏。项目没有接管账号登录，没有使用 LR、DLL 注入或修改游戏二进制。

## 开始使用

运行要求：**Windows 10 / Windows 11 64 位 + .NET Framework 4.8 或更高版本**。Win10 22H2 已自带 .NET Framework 4.8；此版本不承诺 Win7 支持。

1. 从 [Releases](https://github.com/visionki/latale-garden/releases) 下载 `LaTaleGarden.exe`，放在自己方便的位置，双击运行。无需下载源码。
2. 首次使用点“更改”，选择游戏安装目录里的 `LaTaleLauncher.exe`；该目录也应包含 `LaTaleClient.exe`。
3. 退出已经打开的游戏、官方启动器及旧乱码工具，再点“启动游戏”。兼容模式默认开启，Windows 请求管理员权限时由用户确认。
4. 在弹出的官方启动器中完成更新和登录，点击开始游戏。辅助启动器会显示等待和恢复状态。
5. 如有异常，打开“启动记录”查看或导出日志；显示“恢复原设置”时，先完成恢复再重新尝试。

设置页可调整最长等待时间（默认 30 分钟）、初始化等待时间（默认 20 秒）及成功后收起到托盘。检测到本次新客户端后，至少等待初始化时间，并要求窗口连续可见 3 秒，再恢复原区域。

“显示启动器”会切到官方启动器；“显示游戏”和“回到游戏”会切到已检测到的游戏窗口。这些按钮不会再启动一份游戏。“游戏已启动”表示客户端已运行，不代表已检查游戏内文字。

取消等待会停止辅助流程并尝试恢复设置，官方启动器或游戏继续由用户控制。重新启动前，请先关闭仍在运行的官方启动器。

## 单文件与数据保存

启动器自身的设置、日志、异常记录和恢复备份统一保存在：

```text
%LOCALAPPDATA%\LaTaleGarden\
├── settings.json              游戏目录与偏好设置
├── error.log                  出现未处理异常时生成
└── Sessions\
    └── <会话标识>\
        ├── request.json       本次启动参数
        ├── status.json        启动状态
        ├── launch.log         启动与恢复日志
        ├── recovery.json      原区域备份与恢复标记
        └── ...                本次辅助流程的状态文件
```

通常对应 `C:\Users\<用户名>\AppData\Local\LaTaleGarden`，位于当前用户目录之内，不会直接堆放到用户目录根部。

- 同一 Windows 账户下，关闭后移动或替换 EXE，仍能读取原来的游戏路径、设置和恢复记录。
- 换电脑或换 Windows 账户，首次使用需要重新选择游戏目录。
- 启动器不会在 EXE 所在目录创建配置、日志或解压素材。手动“导出日志”会写入用户选择的位置；官方游戏自身产生的更新、日志等文件由游戏管理。
- 保留恢复记录是异常恢复所必需的。恢复未完成时不要删除数据目录；确认所有相关进程已退出且原设置已恢复后，删除这个目录可以清除本工具的本地数据。

## 兼容方式与当前限制

兼容模式调用 Windows 的 `Set-WinSystemLocale zh-TW`，随后启动官方启动器。恢复时使用启动前捕获的实际区域，并保留 `Default`、`ACP`、`OEMCP`、`MACCP` 原值，不固定恢复为简体中文。只有核对保存的配置已恢复后，才清除待恢复标记。

**微软规定系统区域更改需要重启后生效。** 原工具的临时切换方式对特定客户端可能有效，但命令执行成功、注册表写入成功或游戏窗口出现，都不能证明该电脑已免重启解决乱码。GUI 和可靠性改进也不能代替 Win10 实测。

临时兼容模式暂不接受 UTF-8 系统代码页 65001；标准启动仍可使用。系统断电、系统崩溃、同时结束所有相关进程、备份丢失等情形下，无法保证即时恢复；再次打开时会检查保留记录。损坏的恢复记录会阻止新的兼容启动，避免覆盖原备份。

已完成：Win11 25H2 上的原生界面、设置保存、日志导出、现有管理员游戏进程识别、22 项流程与 Windows 检查，以及单 EXE 移动位置检查。**尚未验收：真实区域切换后进入游戏的完整流程、游戏中文字和 Win10 实机。** 详见 [VALIDATION.md](VALIDATION.md)。

参考：[Microsoft 系统区域设置](https://learn.microsoft.com/en-us/powershell/module/international/set-winsystemlocale) · [Microsoft .NET Framework 系统要求](https://learn.microsoft.com/en-us/dotnet/framework/get-started/system-requirements)

## 从源码构建

在 Windows x64 安装 .NET Framework 4.8 或更高版本，于仓库根目录运行：

```powershell
.\build.ps1
.\test.ps1
.\test-portable.ps1
```

`build.ps1` 使用系统自带 C# 编译器，默认仅输出 `dist\LaTaleGarden.exe`；无需下载 NuGet 包。`test.ps1` 使用替代系统平台验证故障与恢复流程，不执行实际区域写入或游戏启动。`test-portable.ps1` 把单独的 EXE 放到两个目录，验证嵌入界面、移动后的相同设置和不产生旁边文件。测试结果位于 `test-results`。

| 文件 | 用途 |
| --- | --- |
| `MainWindow.xaml` / `LauncherWindow.cs` | WPF 界面、设置、目录与日志交互。 |
| `LaunchEngine.cs` | 启动、等待、取消、恢复状态机。 |
| `WindowsPlatform.cs` | 系统区域操作、进程识别、窗口切换、命令超时与 Job 管理。 |
| `Program.cs` | 普通界面、管理员辅助进程、独立恢复进程及单实例入口。 |
| `Models.cs` | 用户数据路径、设置、恢复记录、原子 JSON 写入。 |
| `Tests/EngineTests.cs` | 故障场景与只读 Windows 检查。 |
| `Assets/` / `ASSETS.md` | 界面美术、设计参考和生成提示词。 |

## 反馈

提交问题时请说明 Windows 版本、游戏版本、是否启用繁体兼容模式、具体失败阶段，以及游戏内文字是否正常。可附导出的诊断日志；日志中含本机路径和区域信息，公开前请按需要处理个人信息。

本项目是非官方辅助工具，与游戏运营方无隶属关系。首版为本地构建的未签名程序。
